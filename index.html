📩 รายงานจากคนขับ (รอตรวจสอบ)

ประเภทคนขับรถตำแหน่งรายละเอียดรูปภาพเวลา

🗂️ ประวัติรายงานจากคนขับ (ทั้งหมด)

รายงานทุกฉบับจะถูกเก็บไว้ที่นี่ถาวร แม้แอดมินยังไม่อนุมัติหรือกดลบออกจากคิวด้านบนแล้วก็ตาม — ค้นหาย้อนหลังได้ตามวัน เดือน ปี

ตั้งแต่วันที่ ถึงวันที่
วันที่/เวลาแจ้งประเภทคนขับรถรายละเอียดสถานะวันที่ดำเนินการ

📊 Risk Management

คะแนนความเสี่ยงเฉพาะรถบรรทุก คำนวณจากเส้นทาง สภาพอากาศ และเวลา

ประเมินความเสี่ยงตามเส้นทาง

ระดับความเสี่ยง

🟢 ต่ำ (0–29) — เดินทางได้ตามปกติ
🟡 กลาง (30–59) — เพิ่มความระมัดระวัง
🟠 สูง (60–84) — แนะนำเปลี่ยนเวลา/เส้นทาง
🔴 วิกฤต (85–100) — หลีกเลี่ยงการเดินทาง

รถที่มีความเสี่ยงสูงตอนนี้

🚛 Fleet

รายการรถทั้งหมด

🔔 ประวัติการแจ้งเตือน

ทุกครั้งที่คนขับผ่านจุดเสี่ยงและระบบแจ้งเตือน จะถูกบันทึกไว้ที่นี่ แยกตามทะเบียนรถ

ค้นหา / กรองรายการ

ประวัติทุกรายการถูกเก็บถาวรไว้ถาวร ค้นหาย้อนหลังได้ตามวัน เดือน หรือปี

ตั้งแต่วันที่ ถึงวันที่

ประวัติการแจ้งเตือนตามทะเบียนรถ

เวลาทะเบียนรถคนขับจุดเสี่ยงที่ผ่านระดับความรุนแรงเส้นทางระยะที่แจ้งเตือน

🅿️ ระบบวางแผนพักรถ

คำนวณระยะห่างจุดพัก แนะนำจุดเติมน้ำมัน และตรวจสอบระยะขับต่อเนื่อง

วางแผนตามเส้นทาง

เงื่อนไขปัจจุบัน จาก Admin / Settings

จุดพัก ปั๊มน้ำมัน และ Truck Stop บนเส้นทางที่เลือก

ประเภทชื่อจุดระยะจากจุดเริ่มต้นสิ่งอำนวยความสะดวก

🔧 Maintenance

รอบบำรุงรักษา ประวัติซ่อม และคำแนะนำศูนย์บริการระหว่างเส้นทาง

ตารางบำรุงรักษา

ทะเบียนรถเลขไมล์ปัจจุบันบำรุงรักษาครั้งถัดไปสถานะ

ศูนย์ซ่อมแนะนำระหว่างเส้นทาง

ศูนย์บริการเส้นทางใกล้เคียงระยะทางโดยประมาณ

📋 Report / Dashboard

ภาพรวมความปลอดภัยของขบวนรถและเส้นทาง

🚦 การควบคุมความเร็ว

เกินคือเร็วกว่า 80 กม./ชม. — จัดอันดับด้วยสัดส่วนเวลาขับที่วิ่งเกิน ไม่ใช่จำนวนครั้ง

🏆 ระบบคะแนนสะสม

ให้คะแนนคนขับตามพฤติกรรม ใช้จัดอันดับเพื่อพิจารณามอบรางวัล — แอดมินเป็นผู้ตัดสินและมอบรางวัลเองนอกระบบ

ช่วงเวลาการจัดอันดับ

ให้คะแนนด้วยตนเอง (Manual Award)

ใช้สำหรับเกณฑ์ที่ยังไม่ได้ผูกกับระบบอัตโนมัติ หรือให้โบนัส/หักคะแนนเป็นกรณีพิเศษ (ใส่ค่าติดลบเพื่อหักคะแนน)

เกณฑ์การให้คะแนน ปรับคะแนนหรือเพิ่มเกณฑ์ใหม่ได้ที่นี่

เกณฑ์ประเภทคะแนนสถานะ

🏆 อันดับคนขับ

อันดับคนขับทะเบียนรถคะแนนรวมรายละเอียดกิจกรรมล่าสุด

ประวัติการให้คะแนนล่าสุด

เวลาคนขับเกณฑ์ / เหตุผลคะแนนที่มา

⚙️ Admin / Settings

จัดการจุดต่าง ๆ กำหนดระดับความเสี่ยง และผู้ใช้งานระบบ

🎨 ธีมสี

เปลี่ยนหน้าตาแดชบอร์ดได้ตามใจ เผื่อเบื่อธีมเดิม (มีผลเฉพาะเบราว์เซอร์นี้)

เกณฑ์ระดับความเสี่ยง (Risk Threshold)

เงื่อนไขการขับขี่ปลอดภัย

การเชื่อมต่อ Google Maps

ใส่ Google Maps JavaScript API Key ของคุณเพื่อสลับแผนที่หลักเป็น Google Maps (ต้องเปิดใช้งาน Maps JavaScript API ในโปรเจกต์ Google Cloud ของคุณเอง) กุญแจจะถูกเก็บไว้ในเบราว์เซอร์นี้เท่านั้น — ใช้สำหรับแสดงแผนที่เท่านั้น ไม่เกี่ยวกับข้อมูลจราจร (ดูหัวข้อ "การเชื่อมต่อ TomTom" ด้านล่าง)

การเชื่อมต่อ TomTom (ข้อมูลจราจรจริง)

ใส่ TomTom API Key เพื่อดึงข้อมูลจราจรจริง (เทียบเวลาเดินทางตอนรถติดกับตอนถนนโล่ง) มาคำนวณ Network Risk Score แบบเรียลไทม์ในหน้า Risk Management — สมัครฟรีได้ที่ developer.tomtom.com ไม่ต้องผูกบัตรเครดิต (โควต้าฟรี 20,000 ครั้ง/เดือน) กุญแจจะถูกเก็บไว้ในเบราว์เซอร์นี้เท่านั้น — ข้อมูลสภาพอากาศดึงมาแบบอัตโนมัติโดยไม่ต้องใช้กุญแจอยู่แล้ว
